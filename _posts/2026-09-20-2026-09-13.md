- 선도 AI 연구소의 모델 개발비 감속은 IPO 전 수익성 부풀리기와 버블 연장으로 이어질 수 있음
  - 추론 컴퓨팅비를 뺀 매출총이익과 달리 대규모 학습비는 R&D로 처리돼 순손실을 키움
  - OpenAI·Anthropic·Gemini가 함께 최첨단 학습 속도를 늦추면 R&D 전망치가 낮아지고 상장 전 이익 경로가 개선됨
  - 한 곳만 감속하면 경쟁사에 뒤처지므로 동시 감속이 핵심이며, 실제 이행 여부에는 속임수와 이탈 위험이 남음
- AI 데이터센터 투자는 웨이퍼·메모리·전력 제약으로 이미 최대 가동 수준에 묶여 있음
  - 연구소가 장기 지출 계획을 낮춰도 당장 Nvidia·AMD·데이터센터의 공급·출하 수요는 크게 줄지 않음
  - 감속은 메모리 가격 압력을 낮추고 제한된 공급 안에서 투자 지속 가능성을 높일 수 있음
- 연구소의 현금 소진 시점이 늦춰지면 반도체·네오클라우드·데이터센터의 성장 추정 기간도 2028~2030년 이후로 밀림

- AI 버블은 존재하지만 Anthropic의 수익성 악화가 확인되기 전까지는 상승 국면이 지속될 수 있음

  - 데이터센터는 향후 50년의 석유와 같은 전략 자산으로 규제보다 성장 지원을 우선할 가능성이 큼

### 사이버캡 확산은 엣지 검증이 좌우

- 체인 인식 문제의 본질은 FSD의 한계보다 HW3의 카메라 해상도·연산력·메모리 제약
  - HW3는 2019년 사양으로 12코어, 1.2MP 카메라, 8GB RAM 2개를 사용해 가는 수평 물체가 압축 과정에서 사라질 수 있음
  - 점유 네트워크, 시간적 맥락 기억, 고해상도 스킵 연결을 조합하면 보완 가능하지만 HW3에는 처리 여력이 부족함
- HW4와 사이버캡의 상향된 온디바이스 연산 여력이 체인 같은 엣지 케이스 대응의 기반
  - HW4는 20코어, 5MP 카메라, 16GB RAM 2개로 개선됐고 사이버캡은 32GB RAM 2개를 탑재할 가능성이 제기됨
  - 과거 검증으로 통행 금지 구역을 기억해 진입 자체를 피하는 방식도 병행 가능
- 사이버캡 대중화의 최대 변수는 하드웨어가 아니라 지역별 엣지 케이스 검증 기간
  - 오스틴 로보택시 운영 후 사이버캡 투입까지 약 436일이 걸린 흐름을 90일, 나아가 30일 수준으로 줄여야 본격 확산을 입증할 수 있음
  - 지도 정밀 매핑보다는 실제 운행·검증을 거쳐 문제 구역과 예외 상황을 축적하는 사실상 엣지 매핑에 가까움
- FSD 개입 사유 수집은 대규모 엣지 케이스 학습 채널
  - 운전자가 내비게이션·주차·긴급 상황 등으로 개입한 이유를 받아 개선 우선순위를 정할 수 있음
  - V15 출시와 최신 하드웨어 보급이 지역 확장 속도를 높이는 관문
- HW3 차량은 최신 FSD 기능에서 점차 뒤처질 가능성이 큼
  - V14를 HW3용 경량 버전으로 양자화해야 하며, 무리한 기능 탑재는 지연과 안전 리스크를 키울 수 있음
  - 기존 FSD 구매자 반발과 소송 가능성은 남지만 차량 교체·FSD 권리 이전으로 흡수될 여지도 있음
- 사이버캡 수익원은 차량 판매에 더해 앱 플랫폼 수수료와 FSD 구독으로 넓어질 수 있음
  - 운영 품질이 낮은 사업자는 플랫폼에서 배제하고, 청소·충전·정비는 규모를 갖춘 플릿 사업자에게 맡기는 구조가 현실적
  - 개인 소유 일반 차량을 야간 로보택시로 바로 편입하는 모델은 최신 하드웨어와 운영 관리 문제 때문에 초기 실현 가능성이 낮음
- 사이버캡 원가가 마일당 0.25달러 수준까지 낮아지고 운임이 1달러 미만이면 Waymo 대비 가격 경쟁력이 커질 수 있음
  - 다만 차량 금융 비용을 고려하면 사업성은 금리 하락에 민감하며, 저금리가 두 번째 확장 촉매
- 언박싱 제조의 실제 개선과 목표치를 구분해야 함
  - 기존 공정 대비 제조 라인 길이 50% 축소는 발표된 성과지만, 90% 효율 향상은 차량당 5초 생산 대 Model Y 47초라는 목표에서 나온 수치
  - 목표치를 이미 달성한 실적으로 해석하면 밸류에이션 기대가 과도해질 수 있음
- 로드스터의 냉가스 스러스터 비행 시연은 제품 출시보다 기술 과시에 가까울 가능성
  - 상업 주문 시점이 불분명해 이벤트 직후에는 기대 매수보다 차익 실현이 우세할 수 있음
- 미국 EV 수요 둔화 속에서도 테슬라 판매 감소율은 전년 대비 16%로 전체 EV 시장의 30% 감소보다 낮았다는 보도가 나옴
  - 전통 완성차의 EV 후퇴는 테슬라의 선택지 우위에 도움이 되지만 자율주행 리더십을 보장하지는 않음
- 테슬라의 핵심 검증 지표는 새 도시 출시까지 걸리는 시간의 지속적 단축
  - 이 지표와 금리 하락이 동시에 확인돼야 사이버캡 가치가 주가에 본격 반영될 수 있음
- 단기 이벤트보다 최신 하드웨어 전환, 플릿 운영 체계, 지역 확장 속도를 추적할 필요가 있음
